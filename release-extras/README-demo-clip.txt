Video Research Unit demo clip

This zip holds one video, muybridge-horse-in-motion.mp4, Eadweard Muybridge's
"The Horse in Motion" (1878, public domain). See CREDITS.md for the source.

It goes with the patch "Muybridge on the Scan Processor" (patches/6 - Muybridge on the Scan Processor.vcv
in the source repository).

How to use it:
1. Unzip this file anywhere you like.
2. Open the patch in VCV Rack. The Video Player starts with no video.
3. Right-click the Video Player and choose "Open video file...".
4. Pick muybridge-horse-in-motion.mp4 and press PLAY. LOOP is already on.

Any other video file works the same way.
